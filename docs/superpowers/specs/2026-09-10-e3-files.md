## The single grammar source, and how both sides read it

**`kit/grammar/channel-grammar.json` is the one source.** It ships in the kit (so the installed copy is
the same bytes a session's tool reads), it is EMBEDDED into `AIOrchestratorCoreLib` as a resource, and
`ChannelGrammar` parses that resource. `channel-append.sh` reads the kit file with `jq`.

Not generated from either side: a generator would put the truth in a build step, and the build step is
the thing decision 17 already shows nobody re-runs. Two readers of one file, and a test that fails if the
embedded bytes and the kit file differ.
