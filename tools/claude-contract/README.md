# claude-contract — the bridge's contract with the `claude` CLI

**What it verifies.** The behaviours the bridge builds on, measured on Claude Code 2.1.261 (`MEASUREMENTS.md` §M1–M7 of the 2026-09-05 deep study): hooks fire in `-p` and in `-p --resume`; the `--output-format json` result carries `usage`, `total_cost_usd`, `session_id` and **no** `rate_limits`; `--bg` runs a slash command as its first prompt; the messaging socket **holds** an external message unless the receiver started with `--settings '{"crossSessionInbound":"accept"}'`; an in-flight `-p` shows in `claude agents --json`. Plus two things the `PrintRunner` relies on: the session id is chosen by the caller (`--session-id`) and resumed with `--resume`, and a resume turn takes its prompt from stdin.

**Two categories.** `Stub` (always) drives `FakeClaude` — a cross-platform stand-in for `claude` that accepts the same flags, answers from a scenario file (`FAKE_CLAUDE_SCENARIO` or `./fake-claude-scenario.json`: result, delay, exit code, `api_error_status`, omitted fields, per-`--name` turn lists) and logs every invocation (`FAKE_CLAUDE_LOG` or `./fake-claude-invocations.jsonl`). `Live` runs only with `CLAUDE_CONTRACT_LIVE=1` against the real binary, with `--model haiku`, and stops + removes every session it starts; its raw evidence lands in `tools/claude-contract/last-run/<stamp>-<test>/` (gitignored).

**How to run.** `dotnet test tools/claude-contract/ClaudeContract.Tests` (stub, offline, seconds). `CLAUDE_CONTRACT_LIVE=1 dotnet test tools/claude-contract/ClaudeContract.Tests` (live, minutes, needs a logged-in `claude`; on Windows run it from a Git Bash-capable machine — the socket measure needs the auth line there and is not implemented). The same fake is what the CoreLib `PrintRunner` tests launch.

**When the CLI changes shape.** Run the Live category first — it is the only thing that notices a silent upgrade (`--help` hides flags; HANDOFF.md records what an unnoticed change cost). Read `last-run/`: if a measure moved, update `ResultJson_Builder` / `FakeClaudeArguments` so the fake matches the new truth, then the bridge, then the Stub tests — the fake must never be "fixed" to what the bridge wishes were true.
